# Attila modding marketplace

Install the Total War: Attila modding toolkit:

```bash
claude plugin marketplace add <owner>/<repo>
claude plugin install attila-toolkit@attila-modding
```

When the plugin is enabled you are asked for the Attila folder, the RPFM folder and a few options; leave them blank to auto-detect. Details: `plugins/attila-toolkit/README.md`.
